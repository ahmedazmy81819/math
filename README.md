# Financial Hub - Corporate Finance Reference

A professional, responsive, dark-mode financial calculator hub covering all major corporate finance formulas and ratios.

## Features

- **17 Interactive Calculators** covering:
  - Liquidity Ratios (Current, Quick, Cash)
  - Solvency Ratios (Debt-to-Asset, Times Interest Earned)
  - Activity/Efficiency Ratios (Inventory Turnover, AR Turnover, Asset Turnover)
  - Profitability Ratios (Net Profit Margin, ROA, ROE, EPS, P/E)
  - Cash Flow Analysis (NOPAT, OCF, FCF)
  - Cash Budget Analysis

- **Professional Design**:
  - Mobile-first responsive layout
  - Dark mode optimized with glassmorphism effects
  - Touch-friendly controls (minimum 44px tap targets)
  - Proper formula rendering with MathJax
  - Color-coded sections by financial category
  - Intelligent result interpretation with status indicators

- **Device Compatibility**:
  - iPhone & Android smartphones
  - iPad & tablets
  - Laptops & desktop computers
  - Large screen displays & TVs

## Usage

Simply open `index.html` in any modern web browser. No installation or server required.

Enter values in the input fields and click "Calculate" to see instant results with financial interpretation.

## Formulas Included

All formulas follow standard corporate finance definitions with proper LaTeX rendering:

- Current Ratio = Current Assets / Current Liabilities
- Quick Ratio = (Current Assets - Inventory) / Current Liabilities
- Cash Ratio = (Cash + Equivalents) / Current Liabilities
- Debt-to-Asset Ratio = (Total Liabilities / Total Assets) × 100
- Times Interest Earned = EBIT / Interest Expense
- Inventory Turnover = COGS / Average Inventory
- AR Turnover = Net Credit Sales / Average Receivables
- Asset Turnover = Net Sales / Average Total Assets
- Net Profit Margin = (Net Income / Net Sales) × 100
- ROA = (Net Income / Average Total Assets) × 100
- ROE = (Net Income / Average Equity) × 100
- EPS = (Net Income - Preferred Dividends) / Weighted Average Shares
- P/E Ratio = Market Price Per Share / EPS
- NOPAT = EBIT × (1 - Tax Rate)
- OCF = NOPAT + Depreciation
- FCF = OCF - Net Fixed Asset Investment - Net Current Asset Investment
- Cash Position = Beginning Balance + Receipts - Disbursements
