بناءً على بروتوكول التجهيز واستكمالاً للخطوات، المطلوب الآن هو بناء "مرجع رقمي تفاعلي للقوانين والتحليل المالي" (Financial Formulas & Analysis Hub) بطريقة احترافية وعصرية جداً (High-Craft Web App).

يرجى الالتزام بالمتطلبات والمعايير التالية أثناء التطوير:

---

### 1. الهدف والمحتوى الأساسي (Core Content):
تحويل كافة القوانين والشروحات والرموز المذكورة في ملف `financial_formulas_and_analysis_guide.md` إلى موقع تفاعلي متكامل يغطي المحاور التالية:
1. **التحليل المالي (Horizontal & Vertical Analysis):** التغير السنوي، وقوائم الدخل والميزانية.
2. **نسب السيولة (Liquidity Ratios):** Current, Quick, Cash Ratios.
3. **نسب الملاءة والديون (Solvency Ratios):** Debt to Asset, Times Interest Earned.
4. **نسب الربحية (Profitability Ratios):** Profit Margin, Asset Turnover, ROA, ROE, EPS, P/E Ratio.
5. **التدفقات النقدية (Cash Flows):** NOPAT, OCF, FCF, FCFF والـ Capital Investments.
6. **مصطلحات موازنة النقدية (Cash Budget Terms):** المقبوضات، المدفوعات، الفائض، والعجز.

---

### 2. الميزات التفاعلية الاحترافية (Key Interactive Features):

* **آلة حاسبة مالية تفاعلية (Interactive Financial Calculators):**
  - لكل قانون، توفير نموذج إدخال أرقام (Input Form) يحسب النتيجة فورياً مع عرض التفسير المالي للنتيجة (مثلاً: نسبة سيولة جيدة / مرتفعة المخاطر).
* **معادلات رياضية منسقة (KaTeX / MathJax Integration):**
  - عرض كافة القوانين الرياضية بصيغ أنيقة بأسلوب LaTeX ملفت ومقروء بدقة عالية.
* **دليل المصطلحات والرموز الشامل (Glossary & Legend System):**
  - عند الضغط على أي رمز أو مصطلح (مثل COGS, EBIT, NOPAT) يظهر كارت تفاعلي (Tooltip/Popover) يوضح معناه وشرحه المالي بالتفصيل.
* **بحث وتصفية ذكية (Instant Search & Category Filtering):**
  - شريط بحث حي يتيح للتعامل السريع الوصول لأي قانون أو مصطلح باللغة العربية أو الإنجليزية.
* **محددات الوضع الداكن والتصميم (Dark Mode First):**
  - تصميم عصري بأسلوب Dark Mode داكن واحترافي يراعي تباين الألوان والـ Typography والـ Spacing المريح للعين.
* **خيارات التصدير والمشاركة (Export & Print):**
  - إمكانية طباعة أو تصدير القانون أو نتيجة الحساب كـ PDF أو نسخته كـ MathML/Markdown بضغطة زر.

---

### 3. المعايير التقنية والتصميمة (Strict Technical & Design Rules):
- **الالتزام الكامل بـ `CLAUDE.md`:** تنفيذ كافة المراحل المقررة من تصميم (Taste & Design System) وضمان التفاعل الكامل مع الـ DOM بدون أخطاء Runtime.
- **التجاوب (Responsive Layout):** توافق كامل مع كافة الشاشات (الهواتف المحمولة، التابلت، وشاشات الحواسيب).
- **الأداء والسرعة (Clean Code):** كود نقي ومبسط بدون مكتبات ثقيلة غير ضرورية، مع دعم التدوين باللغة العربية (RTL) بسلاسة كاملة.

---

### 4. الفحص والمرئيات (Visual Verification Protocol):
بعد إنشاء وتحديث الملفات، قم بتشغيل Stage 3 إجبارياً عبر `playwright-cli:visual-check` للتأكد من:
1. أخذ لقطات شاشة (Screenshots) للموقع للتأكد من سلامة الهيكل والألوان.
2. تجربة النقر على الحاسبات والأزرار للتأكد من عدم وجود أخطاء في الـ JavaScript Console.

ابدأ الآن فوراً بتنفيذ المرحلة الأولى ثم إنتاج الكود واختباره.
